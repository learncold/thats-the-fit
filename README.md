# 대츠더핏 · THAT’S THE FIT

의류 실측과 핏 키워드 기반 데님 검색 서비스 프로젝트다

## 기술 스택

| 항목 | 설정 |
| --- | --- |
| Java | 21 |
| Spring Boot | 4.1.2 |
| Maven | 3.10.0 |

## 빌드·테스트

```powershell
# Windows PowerShell
.\mvnw.cmd clean verify
```

```sh
# Linux / macOS
sh ./mvnw clean verify
```

## 실행

```powershell
.\mvnw.cmd spring-boot:run
```

빌드한 실행 JAR로도 시작할 수 있다.

```sh
java -jar target/thats-the-fit-0.0.1-SNAPSHOT.jar
```
